# Gl Project

## Overview

This project is structured to maintain a clean and organized codebase

## Project Structure

```plaintext
├── src
│   ├── api
│   │   └── routeName
│   │       └── route.js
│   │       └── ... (additional routes)
│   │
│   ├── components   (for components that will be reused in multiple pages)
│   │   ├── layout
│   │   │   └── index.js (exports for layout components like Navbar, Footer, etc.)
│   │   │   └── ... (layout components)
│   │   ├── ui
│   │       └── index.js (exports for reusable UI components like Button, Modal, etc.)
│   │       └── ... (UI components)
│   │
│   ├── page1
│   │   ├── components
│   │   │   └── index.js (exports for page-specific components)
│   │   │   └── comp1.jsx
│   │   │   └── ... (additional page-specific components)
│   │   ├── page.jsx
│   │   ├── Error.jsx
│   │   └── loading.jsx
│   │
│   ├── assets
│   │   ├── images
│   │   │   └── example.jpg
│   │   │   └── ... (additional images)
│   │   ├── svgs
│   │       └── example.svg
│   │       └── ... (additional SVGs)
│   │
│   └── lib
│       └── index.js (frequently used utility functions)
```
